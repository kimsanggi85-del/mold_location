전수 실사 점검표 · 보관장 포함

매월 정기 실사는 현황판 탭의 “실사 시작”으로 프레스 라인만 도는 것을 권합니다. 이 표는 보관장까지 포함한 전수 실사용입니다(연 1~2회 권장). 불일치로 판정하면 현황판에 위치 불일치 알람이 뜨고, 해당 호기 타일에도 표시됩니다. 알람은 자동으로 사라지지 않습니다 — 현물을 다시 확인하고 위치 보정을 실행해야 해제되며, 그 과정이 이동 이력에 남습니다. 부적합 발생부터 시정까지의 흐름이 그대로 기록되므로, 저장된 실사 기록이 “해당 일자 기준 현황판이 실물과 일치함”을 증명하는 기록이 됩니다.

Supabase 연결

사내 공용 담당자·PIN 마스터(user_pins)를 사용합니다. 등록 시 본인 PIN을 입력하면 담당자 이름이 자동으로 기록됩니다. 금형 수리관리 시스템과 같은 PIN입니다.

배포본에는 연결정보가 들어 있어 기기마다 입력할 필요가 없습니다. 등록·수정 시에만 PIN을 물어봅니다. PIN은 파일에 없으므로 아는 사람만 기록할 수 있습니다.
서버에 연결되면 화면은 서버 데이터를 표시합니다. 파일을 새로 받아도 서버 내용이 옛날이면 옛날 상태가 보입니다. 이때 서버 데이터 재업로드를 실행하세요.
한 번 저장하면 이 단말에서는 계속 유지됩니다. 다음부터는 열자마자 자동 연결됩니다. 연결 전에는 파일에 내장된 데이터(금형 건 · 이력 건)로 동작합니다.

설정 QR — 다른 단말 자동 연결

이 QR을 인쇄해 현장에 붙이면, 작업자는 스캔 한 번으로 설정이 끝납니다. 이후에는 주소만 열어도 자동 연결됩니다. 연결 정보가 저장소에 올라가지 않으므로, 이 종이만 사내에서 관리하면 됩니다.

kv_store 테이블

사내 다른 시스템(금형 수리관리·설비점검 등)과 같은 테이블을 사용합니다. 이미 있으면 실행하지 않아도 됩니다.
